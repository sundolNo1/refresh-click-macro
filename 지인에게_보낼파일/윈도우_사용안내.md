# 윈도우용 앱(EXE) 만들기 · 사용 안내

## A. EXE 파일 만들기 (윈도우 PC에서 한 번만)

> `.exe` 는 윈도우에서만 만들 수 있습니다. 아래는 **윈도우 컴퓨터**에서 진행합니다.

### 준비물
- 인터넷 연결
- 파이썬 설치 — https://www.python.org/downloads/
  - 설치 화면 맨 아래 **"Add Python to PATH"** 체크박스를 **꼭 체크**하세요.

### 만드는 법 (아주 쉬움)
1. 이 폴더(`매크로.py`, `EXE_만들기.bat` 가 있는 폴더)를 윈도우 PC로 복사합니다.
2. **`EXE_만들기.bat`** 파일을 **더블클릭**합니다.
3. 검은 창이 뜨고 자동으로 설치 → 빌드가 진행됩니다. (처음엔 2~3분)
4. 끝나면 **`dist`** 폴더가 열리고 그 안에 **`자동새로고침매크로.exe`** 가 있습니다.

이 `exe` 파일 **하나만** 다른 윈도우 PC에 복사하면, 파이썬 설치 없이 바로 실행됩니다.

## B. 앱 사용법 (지인분이 쓰는 부분)

`자동새로고침매크로.exe` 를 더블클릭하면 창이 뜹니다.

1. **① 클릭할 위치**
   `이 위치로 지정하기` 버튼을 누르고 → 3초 안에 마우스를 클릭할 곳에 올려두세요.
   → 위치가 초록색으로 저장됩니다.

2. **② 설정**
   - `몇 초마다 새로고침` : 기본 60초 (원하는 숫자로)
   - `새로고침 방식` : 크롬이면 **Ctrl+R** 선택 (또는 F5)
   - `새로고침 후 클릭까지 대기` : 화면이 뜨는 시간. 기본 2초 (느린 페이지는 늘리세요)

3. **③ 인터넷 표준시각 (KST)**
   - `표준시각 동기화` 를 먼저 한 번 눌러 주세요.
   - `표준시각 00초에 맞추기` 를 체크하면 새로고침이 **매분 같은 시각**에 떨어집니다.
     컴퓨터 시계가 아니라 인터넷 표준시각 기준이라 시간이 밀리지 않습니다.
   - **00초보다 살짝 먼저 누르고 싶을 때**: 주기를 그만큼 짧게 넣으면 됩니다.
     - `59.85` → 매분 **59.85초** (00초보다 0.15초 먼저) · 간격은 정확히 60초
     - `29.90` → 매 **:29.90 / :59.90**
     - `60` / `30` / `20` / `15` / `10` → 정확히 00초(및 그 격자)
   - 60초에서 2초 넘게 차이 나는 값(예: `45`, `35.15`)은 당김으로 보지 않고
     **매분 00초**에 맞춥니다. 그 주기 그대로 돌리려면 체크를 **끄세요**.
   - 시작하면 로그에 어떤 방식으로 도는지 한 줄 표시됩니다.

4. **④ 보안문자 감시** (원할 때만)
   보안문자(캡차) 입력란이 뜨면 **소리로 알려주는** 기능입니다. 입력은 직접 하셔야 합니다.
   평소엔 **접혀** 있습니다 — `▶ 펼치기` 를 누르면 열리고, `▼ 접기` 로 다시 접어 창을 짧게 쓸 수 있습니다.
   (접어 두어도 설정과 감시 동작은 그대로 유지됩니다.)
   - `보안문자 입력란이 뜨면 소리로 알림` 체크
   - `① 감시 영역 지정` → 보안문자가 나타나는 자리의 **왼쪽 위 → 오른쪽 아래** 모서리에
     각각 3초 안에 마우스를 올려두세요.
   - 보안문자가 **없는** 평소 화면 상태에서 `② 기준 화면 저장` 을 누르세요.
   - `민감도` : 기본 8. 헛알림이 잦으면 숫자를 올리고(15), 못 잡으면 내리세요(4).
   - `알림이 울리면 매크로 자동 정지` 를 켜 두면, 보안문자가 뜬 화면이
     다음 새로고침에 사라지지 않습니다. (권장)

5. **▶ 시작** (초록 버튼) 을 누르면 자동으로 반복합니다.

### 멈추는 방법 (3가지 중 아무거나)
- **■ 정지** (빨간 버튼)
- 마우스를 **화면 맨 왼쪽 위 모서리**로 확 밀기
- 창을 닫기(X)

## C. 자주 나오는 문제

- **"Windows의 PC 보호" 경고가 떠요**
  → 직접 만든 exe라 서명이 없어서 그렇습니다.
  `추가 정보` → `실행` 을 누르면 됩니다.

- **클릭/새로고침이 안 먹혀요**
  → 대상 창(크롬 등)이 **선택(활성화)** 된 상태여야 합니다.
  시작 전에 대상 창을 한 번 클릭해 두세요.
  → 대상 프로그램이 관리자 권한으로 켜져 있으면, 이 앱도 **관리자 권한으로 실행**하세요
  (exe 우클릭 → 관리자 권한으로 실행).

- **엉뚱한 곳을 클릭해요**
  → 화면 배율(125%/150%)이나 창 위치가 바뀌면 좌표가 달라집니다.
  `이 위치로 지정하기` 로 다시 지정하세요.

- **보안문자 알림이 계속 헛울려요**
  → 감시 영역에 광고·시계처럼 계속 바뀌는 부분이 들어갔을 수 있습니다.
  보안문자 입력란 자리만 좁게 다시 잡고, 민감도 숫자를 올려보세요.
  → 페이지가 바뀌었으면 `② 기준 화면 저장` 을 다시 눌러 기준을 갱신하세요.

- **새 버전을 받았는데도 "사용 기간이 만료되었습니다" 라고 떠요**
  → 이전 버전에서 만료 판정을 받은 기록이 PC에 남아 있어서 그렇습니다.
  그 기록 파일을 지우면 됩니다. **앱을 먼저 완전히 종료**한 뒤:
  1. 키보드 `윈도우키 + R` 을 누릅니다.
  2. 뜨는 칸에 아래를 그대로 붙여넣고 `확인`:
     ```
     %LOCALAPPDATA%\.rcmacro
     ```
  3. 열린 폴더 안의 **`state.dat`** 파일을 지웁니다. (폴더째 지워도 됩니다)
  4. 앱을 다시 실행하면 새 사용 기한으로 정상 동작합니다.

  → 폴더가 안 열리면 `%USERPROFILE%\.rcmacro` 도 같은 방법으로 확인해 보세요.
  → 지워도 계속 만료라고 나오면, 실제로 사용 기한이 지난 것입니다.
  창 위쪽에 표시되는 `사용 가능 기간: ~날짜` 를 확인하세요.

- **백신이 exe를 차단해요**
  → PyInstaller로 만든 exe가 가끔 오탐지됩니다. 예외 처리하거나,
  정 안 되면 파이썬으로 `python 매크로.py` 직접 실행해도 동일하게 동작합니다.
