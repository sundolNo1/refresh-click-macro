# 주기적 새로고침 + 좌표 클릭 매크로

지정한 주기마다 활성 창을 새로고침(키 입력)하고, 잠시 대기한 뒤 지정한 화면 좌표를
클릭하는 동작을 반복하는 CLI 매크로입니다.

- 타이밍 드리프트 방지: `perf_counter` 절대 시각 기반 스케줄링 (`next_run += interval`)
- 주기 기준점은 **새로고침 시점** — `--wait` 를 바꿔도 새로고침 간격은 `--interval` 로 유지
- 대기 중에도 ESC 를 누르면 남은 시간을 기다리지 않고 즉시 중단

## 설치

```bash
# (권장) 가상환경
python3 -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

- Python 3.11 이상 권장 (3.9+ 동작)
- `pynput` 이 없어도 실행됩니다. 이 경우 ESC 중단만 비활성화되고 나머지는 정상 동작합니다.

## 사용법

### 1) 좌표 확인 모드

클릭할 위치의 화면 좌표를 먼저 확인합니다.

```bash
python refresh_click_macro.py --pos
```

20초 동안 마우스를 클릭할 위치로 옮기면 실시간 좌표가 표시되고,
종료 시 `-x -y` 에 넣을 값을 안내합니다.

### 2) 매크로 실행

```bash
# 기본값(59.99초 주기, F5 새로고침, 새로고침 2초 뒤 1회 클릭)
python refresh_click_macro.py -x 640 -y 400

# 크롬을 Ctrl+R 로 새로고침, 30초 주기, 새로고침 1.5초 뒤 클릭
python refresh_click_macro.py -x 640 -y 400 --key ctrl+r --interval 30 --wait 1.5

# macOS 크롬(Cmd+R), 3회만 반복
python refresh_click_macro.py -x 640 -y 400 --key command+r --limit 3

# 빠른 타이밍 검증
python refresh_click_macro.py -x 640 -y 400 --interval 3 --wait 0.5 --limit 3
```

동작 순서: **[새로고침 키] → [로딩 대기(--wait)] → [좌표 클릭] → 다음 주기까지 대기 → 반복**

### 옵션

| 옵션 | 기본값 | 설명 |
|------|--------|------|
| `--pos` | - | 좌표 확인 모드 |
| `-x`, `-y` | 필수 | 클릭할 좌표 |
| `--interval` | 59.99 | 새로고침 주기(초) |
| `--wait` | 2.0 | 새로고침 후 클릭까지 대기(초) |
| `--key` | f5 | 새로고침 키. `ctrl+r` 처럼 `+` 로 조합 |
| `--clicks` | 1 | 클릭 횟수 |
| `--limit` | 0 | 총 반복 횟수 (0이면 무제한) |
| `--delay` | 5.0 | 시작 전 대기(초) |

## 중단 방법 (3가지)

1. **ESC 키** — pynput 리스너 (미설치 시 비활성)
2. **Ctrl+C** — 정상 종료 메시지 출력 후 종료
3. **FAILSAFE** — 마우스를 화면 **좌측 상단 모서리(0,0)** 로 이동

## OS별 주의사항

### macOS
- **접근성 권한 필수.** 매크로가 키/마우스를 제어하려면 실행하는 프로그램(터미널,
  iTerm, VS Code 등)에 권한을 줘야 합니다.
  - `시스템 설정 → 개인정보 보호 및 보안 → 손쉬운 사용` 에서 사용 중인 터미널 앱을 추가/체크
  - ESC 감지(pynput)에는 `입력 모니터링` 권한도 필요할 수 있습니다.
  - 권한 변경 후에는 터미널을 완전히 종료했다가 다시 실행하세요.
- 크롬 새로고침 키는 **`command+r`** 입니다. (`--key command+r`)
- 좌표는 **논리 픽셀** 기준입니다. Retina 디스플레이에서 좌표가 예상과 다르면
  `--pos` 로 실제 값을 다시 확인하세요.

### Windows 11
- 대상 프로그램이 **관리자 권한**으로 실행 중이면, 매크로도 **관리자 권한 터미널**에서
  실행해야 키/클릭이 전달됩니다.
- 크롬 새로고침 키는 `f5` 또는 `ctrl+r` 입니다.
- 디스플레이 배율(125%/150%)에 따라 좌표가 달라질 수 있으니 `--pos` 로 확인하세요.

### Ubuntu / Linux
- **X11 환경**에서 동작합니다. Wayland 세션에서는 pyautogui/pynput 이 제대로
  동작하지 않을 수 있으니 X11 로 로그인하세요.
- 의존 패키지가 필요할 수 있습니다:
  ```bash
  sudo apt install python3-tk python3-dev scrot
  ```

## 문제 해결

- **클릭/키가 전혀 안 먹힘** → 접근성/관리자 권한 문제일 가능성이 큽니다(위 참고).
- **좌표가 엉뚱한 곳을 클릭** → 디스플레이 배율/Retina 문제. `--pos` 로 재확인.
- **ESC 가 안 먹힘** → pynput 미설치 또는 입력 모니터링 권한 부족. Ctrl+C 를 쓰세요.
- **새로고침이 안 됨** → 대상 창이 활성화(포커스)되어 있어야 합니다. `--delay` 동안
  대상 창을 클릭해 활성화하세요. 새로고침 키가 OS/앱에 맞는지 확인(`--key`).
- **급하게 멈추고 싶을 때** → 마우스를 화면 **좌측 상단 모서리**로 튕기세요(FAILSAFE).
